# PRD：DOS 模拟器触屏操作真实化（触摸直接定位模式）

- 状态：**已交付**（ArkTS 手势层，纯 `EmulatorScreen` 改动，引擎与坐标映射链路零改动）
- 交付提交：`63447b7`（R1 滑动纯移动 / R2 双击 / R3 双击按住拖拽 / R4 零回归）、`cb29304`（双击窗口清理路径收敛）
- 当前行为基线以 [`AGENTS.md`](../AGENTS.md) 的触摸手势条目与 `entry/src/main/ets/view/EmulatorScreen.ets` 为准；
  本文保留需求原文与验收口径。

## 背景

NextDOS 的触摸输入已运行在引擎 seamless 绝对指针链路上（`[mouse] mouse_capture = seamless`，
INT 33h 光标跟随 `injectMouse` 绝对坐标，绘制矩形由引擎统一下发，单一事实源映射已交付并真机验证）。
但单指手势语义仍残留"触控板式"设计：**滑动越出 slop 即按住左键拖拽**，用户无法在不触发按键的前提下
平滑移动光标；双击语义依赖两次快速点按的隐式时序，无显式手势定义。

本 PRD 将触摸交互升级为"真实触摸屏直接定位"模式：手指即光标，滑动只是移动，点击才是按键。

## 现状基线（改动前：`feature/mouse` @ 21d3a0e，`EmulatorScreen.ets`）

- 手指按下（Down）即 `injectMove` 绝对定位光标 ✅ 已实现
- tap（<10vp slosh 内抬起，长按定时器未触发）= 左键点击对 ✅ 已实现
- 滑动越 slop（10vp）= **按下左键并拖拽**（本次要改）
- 长按 480ms = 右键，按住后移动 = 右键拖拽 ✅ 保留
- 双指平移 = 滚轮（48vp/格 + 动量滑行）、双指快抬（≤250ms 且 <0.5 格）= 中键 ✅ 保留
- 双击：无显式处理（两次快速 tap 在 guest 侧天然构成双击，但拖拽手势改造需显式双击窗口判定）
- 物理鼠标路径（onMouse/onAxisEvent）与触摸路径互不共享状态 ✅ 保留

## 需求

### R1 滑动改为纯光标移动（核心变更）

单指按下后滑动（越出 slop 半径）：光标平滑跟随手指绝对位置移动，**不按下任何鼠标键**。
移动必须逐 Move 事件注入（沿用现有 injectMove 绝对+相对链路），无可感顿挫。

### R2 双击 = 左键双击（显式化）

两次快速单指点击（时间窗口 + 位移容差内）构成双击：两次点击对原样注入（guest 侧按自身时序
判定为双击），不得因手势状态机引入额外延迟或事件吞并。

### R3 左键拖拽改由"双击按住滑动"触发（兼容性替代手势）

为保留拖拽能力（框选、滑块、游戏内拖拽）：第二次点按落下后在双击窗口内、越出 slop 进入移动时，
按下左键并随手指拖拽，抬指释放左键。语义 = 经典触控板 tap-tap-hold-drag。
若第二次点按在 slosh 内快速抬起，则按 R2 交付普通双击。

### R4 既有手势零回归

以下行为不得变化：点击定位（按下即移动光标）、长按 480ms=右键、长按后移动=右键拖拽、
双指平移=滚轮+动量、双指快抬=中键、Cancel 只释放不点击、物理鼠标/滚轮路径、
引擎绘制矩形单一事实源映射。

### R5 定位精度 ≤ 2 像素

点击定位与滑动跟随时，视觉光标位置与手指触点映射位置误差 ≤ 2 像素（帧坐标系）。
不得引入第二套 letterbox 或自算映射。

### R6 多设备适配与验证

手机（强制横屏）/平板/2in1 三形态下手势行为一致；不同分辨率/像素密度下映射比例自洽。
平板 XYAO-W00 真机验证核心手势链；构建门禁（hvigorw + codelinter）双绿。

## 非目标

- 不改引擎侧（ohos_input/ohos_gui/native 映射链路）——纯 ArkTS 手势层变更
- 不新增物理鼠标路径行为
- 不做应用内手势设置开关
